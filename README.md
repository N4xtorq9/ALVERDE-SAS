# 🌿 ALVERDE SAS
## Ingeniería Sostenible
<br>
Sitio web corporativo de **ALVERDE S.A.S**, enfocado en presentar sus servicios, proyectos y soluciones de ingeniería civil y ambiental.

## 📌 Descripción

Proyecto web que reúne información corporativa, servicios especializados y proyectos desarrollados por **ALVERDE S.A.S**, con una presentación visual orientada a la ingeniería y la sostenibilidad.

## 🚀 Servicios y áreas de trabajo

- 🌱 Hidrosiembra y revegetalización.
  
- 🌳 Reforestación y paisajismo.
  
- 🏗️ Construcción e infraestructura.
  
- 🪨 Estabilización de terrenos y anclajes.
  
- 🚧 Cercos y obras especializadas.
  
- 🚜 Maquinaria y equipos.

## 💻 Instalación y ejecución

1. Clona el repositorio:
   
   ```
   git clone https://github.com/N4xtorq9/ALVERDE-SAS.git
   ```
   
2. Ingresa a la carpeta:
   
   ```
   cd ALVERDE-SAS
   ```
   
3. Abre `index.html` en tu navegador o utiliza la extensión **Live Server** de Visual Studio Code.
   

## 🎯 Objetivo

Presentar de forma clara y organizada la identidad corporativa, los servicios y los proyectos de **ALVERDE S.A.S** mediante una plataforma web.
